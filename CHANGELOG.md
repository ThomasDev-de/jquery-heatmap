# Changelog

All notable changes to this project are documented in this file.

## [1.0.5] - 2026-07-16

### Added

- Added the `click` option for handling heatmap cell clicks.
- Added click callback documentation to the README.
- Added a complete English demo page with multiple heatmap examples, custom colors, live updates, tooltips, and cell selection.

### Changed

- Bumped the package and plugin version from `1.0.4` to `1.0.5`.
- Regenerated the minified distribution file from the updated plugin source.
