API usage

Minimal click callback configuration

The first callback argument is the jQuery cell, so existing code can read attributes with cell.attr('title').

$('#heatmap-container').heatmap({
    data: activityData,
    click: function (cell, dayEntry, event) {
        console.log(cell.attr('title'));
        console.log(dayEntry.date, dayEntry.count);
    },
});
